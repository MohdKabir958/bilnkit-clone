# Confirmed pickup locations and coverage

Add Vendor now searches places through the existing server-side Photon-compatible adapter, lets the operator select a suggested address, adjust a map pin, and explicitly confirm the entrance. The manual coordinate fallback is expandable and labelled. No default landmark or camera position is submitted as a store location. Changing address/city/pin invalidates confirmation. The Access step previews active city coverage circles and emphasizes the selected eligible zone. Dragging that preview returns to pickup confirmation; covering zones are recomputed with the authoritative Haversine rules.

Vendor details use the same picker. The new administrator-only confirmed-pickup endpoint requires India coordinates, confirmation and SEARCH/MAP/MANUAL metadata. It locks the store, refuses changes while orders are active, and atomically closes a moved store, pauses its existing coverage and records old/new coordinates and operator/method in audit. Reopening requires coverage review and the existing backend checks. Historical pin APIs and source identifiers stay compatible.

## Provider setup and licences

The existing backend MAPS_GEOCODER_URL points to an authorized HTTPS Photon-compatible endpoint. Optional MAPS_PROVIDER_TOKEN stays on the backend. Search is authenticated, rate-limited (30/user/minute), has a 5-second timeout and bounded responses. No search provider or paid service has been created. If absent, a 503 explains manual/GPS alternatives; this UI supplies manual verified coordinates. The request is forwarded only to the operator-configured endpoint, not an arbitrary URL from a browser.

The existing VITE_MAP_TILE_URL configures an authorized HTTPS tile service. No production tile provider is assumed. With no tiles, the map displays its explicit missing-background notice while pin/circle geometry remains usable. Confirm locations independently before saving. Add only the exact trusted tile origin to Vercel img-src CSP when enabling tiles; do not use wildcard origins or browser secret keys. Public restricted tile keys may be public by design; server secrets must stay server-side.

Leaflet 1.9.4 is already installed (BSD-2-Clause; see its package LICENSE). Photon software is Apache-2.0; underlying OpenStreetMap data has ODbL attribution obligations.
