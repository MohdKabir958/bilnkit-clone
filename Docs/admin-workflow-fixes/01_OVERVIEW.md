# Marketplace Overview

`GET /api/v1/admin/dashboard` requires authenticated backend-approved administrator access. Today/7/30/90 use IST calendar days through request time. City filtering runs in PostgreSQL; aggregates use a repeatable-read transaction and an 8-second per-statement timeout. No orders or personal records are returned by this aggregate endpoint. Added order-created and vendor/date indexes support the bounded queries.

Counts are store orders: multi-store checkout counts once per store. Captured online means positive provider-verified Payment.capturedAmountPaise, not order paymentStatus or promised totals. Cash received uses PLATFORM_RECEIPT evidence with the existing historical remittedAt fallback only when receipt events are absent. Joining pre-aggregated sources prevents multiple attempts/events multiplying totals. Outstanding cash remains separate. All money uses the order-created cohort and is gross before refunds; these values are not net revenue or settled payouts. Store approvals and rider duty are current snapshots independent of order range.

Charts reuse Recharts and Grozo tokens. All graphical selections have keyboard-equivalent text buttons/tables. Orders drill-downs use the exact server date interval, city, vendor, status, payment method, active or exception filter; they have independent server pagination, preventing ordinary socket/poll lists overwriting their results. Rider duty filters apply to the current selected-city roster. Clear selection returns to the normal workflow. Date choice persists when navigating back. Legacy reporting endpoint remains compatible; older servers show an explicit version mismatch instead of fabricated figures.

Verified: 7 focused UI tests, 16 backend unit tests (range/readiness diagnostics), admin TypeScript passed. Logs are in evidence/task-1-*. Full PostgreSQL aggregation/authorization tests exist in overview_dashboard.test.ts and remain pending the isolated database environment. Real chart rendering and staging browser acceptance are not claimed by these mocked chart/unit tests.
