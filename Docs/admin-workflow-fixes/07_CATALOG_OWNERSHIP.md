# Vendor ownership and catalog oversight

Daily product creation/editing, price proposals, shelf counts, lots/expiry, packing/returns and working hours remain in the Vendor app for approved owned stores. Existing grocery inventory backend regressions already assert another vendor cannot mutate products and stock reservations remain server-controlled. The Vendor preparation settings screen persists operatingHours through the existing contract. These workflows have not been replaced.

Admin navigation is now Catalog oversight. Normal actions inspect photos, approval, stock history, lots/reservations and approve/reject pending products. Product creation/editing and stock changes appear only after **Exceptional store assistance**: select one store, enter a useful reason and explicitly confirm authorization. The backend records the operator/store/reason, returns an hour-long assistance reference, and validates that reference on each matching write. Different operator, store, expired or forged references fail. Successful writes record an assistance-applied audit inside their existing transaction. Stock version, reservation, pricing, expiry and idempotency checks remain unchanged. The UI expires/ends assistance without deleting any records.

Existing administrative APIs retain authorized emergency/backwards compatibility behavior for older clients that do not submit an assistance reference; their prior business audits remain. Assistance creates no new role or permission. Vendor callers cannot use an administrative assistance reference. Approval/rejection remain separate moderation controls; the exceptional record does not auto-approve a vendor or delivery partner.

Verified: 13 focused UI tests passed before adding one further read-only assertion. Admin TypeScript passes. New database regressions cover consent, scope, audit, expiry and cross-vendor denial; execution remains blocked by the isolated database environment. The full admin suite and new read-only check are recorded in integration evidence. No external account or hosted catalog was changed.
