# External services and ownership

PostgreSQL stores application records. Firebase Core/Messaging and local notifications remain in all three mobile apps; the backend uses Firebase Admin. No Firestore or Firebase Auth data layer was found.

| Service | Implemented integration | Required configuration / unverified boundary |
|---|---|---|
| FCM | Transactional notification outbox, recipient claims/retries, stale event suppression, dead-token cleanup, personal dispatch offers; Flutter foreground/background handlers, notification navigation and per-account token ownership | Own a Firebase project and register `in.grozo.customer`, `.vendor`, `.driver`. Supply matching ignored `android/app/google-services.json` files and backend-only `FIREBASE_KEY_PATH`. Test permission denial, refresh, account switch, foreground/background/terminated delivery on real Android devices. No real FCM sends were verified here. |
| Customer Google sign-in | Backend Google ID-token verification and JWT sessions; test-only verifier injection | Set backend `GOOGLE_WEB_CLIENT_ID`, mobile `GOOGLE_SERVER_CLIENT_ID`, matching Android clients and signing SHA fingerprints in the owned Google project. Real OAuth remains unverified. Customer login is not SMS OTP. |
| Razorpay | Real order/capture lookup, signature/webhook verification, integer-paise ledger, duplicate handling and cancellation/refund recovery | Configure TEST public ID, secret and webhook secret in backend; use `PAYMENT_PROVIDER=razorpay`. Normal development defaults to disabled payments, never simulated success. Automated integration tests inject an explicitly simulated provider. External sandbox UPI/capture/refund remains unverified; no live payments enabled. |
| Payouts | Vendor/rider settlement and audited manual bank-reference ledger | Automatic bank disbursement is unavailable. Reconcile bank statements manually; do not treat marking a settlement paid as a provider transfer. |
| Maps | Configurable HTTPS Photon-compatible geocoder and OSRM-compatible router, bounded payloads/timeouts, role-checked routes; foreground manual/GPS address entry | Set `MAPS_GEOCODER_URL`, `MAPS_ROUTER_URL` and optional server-only token. Admin tile URL/attribution are configurable. Use an owned/licensed provider; public OSM endpoints are not production defaults. Live maps, GPS accuracy and navigation require device/provider verification. |
| Product images | Vendor-owned/admin writes; JPEG/PNG/WebP signature/dimension/size/quota validation, random filenames, immutable public reads with nosniff | Persistent upload volume and filesystem backup/restore path supplied. `PUBLIC_BASE_URL` must be the owned HTTPS origin in production; development HTTP is allowed only for generated upload paths on the configured origin. Object-storage/CDN adapter is not implemented; one persistent API instance is the initial deployment model. |
| SMS | No external SMS provider | Doorstep OTP is generated server-side and visible to the authenticated customer. SMS delivery/customer phone OTP login is not claimed. |

Server keys never belong in Flutter, public web bundles or Git. Upstream Firebase client files were removed; debug APKs can explicitly bypass Firebase to verify compilation, but release builds reject that flag. Release signing requires the operator's keystore and matching Firebase/Google registration. Configure the real support email in `branding/brand.json`; no upstream email receives pilot requests. Authenticated support cases work without an email provider.

The cloud environment downloads Node packages, Prisma engines, Flutter/pub artifacts and Android/JDK toolchains. Service egress and secrets must be configured for the operator's actual providers before external validation. Do not infer rights to original logos/photos/domains or external service accounts from the MIT code license.
